Monatsübersicht

Jeder Tag ist geteilt: oben die Arbeitsschicht, unten die Rufbereitschaft – beides läuft am selben Tag nebeneinander. Ein Klick auf das obere Feld trägt die gewählte Arbeitsschicht ein oder aus, ein Klick auf den unteren Streifen die Rufbereitschaft. Mit Shift+Klick geht es vom zuletzt geklickten Tag (blau umrandet) bis hierher – innerhalb derselben Zeile, also eine ganze Woche Rufbereitschaft in zwei Klicks. Ein belegtes Feld lässt sich auf einen anderen Tag ziehen, ebenfalls nur in derselben Zeile.

Rufbereitschaft

Je Kalenderwoche eine oder mehrere Personen zuweisen – Klick auf eine Zelle öffnet die Auswahl. Die Spalte Im Kalender zeigt, was davon tatsächlich in den Tagen steht; ▶ In den Kalender übertragen gleicht beides an.

⚙ Autoplan-Template
Lege pro Mitarbeiter fest, welche Schicht er an welchem Wochentag hat. Der Autoplan übernimmt exakt dieses Muster.
Klick auf eine Zelle wechselt zwischen Früh → Normaldienst → Spät → Frei → leer. Rufbereitschaft steht hier nicht: sie wird im Reiter Rufbereitschaft wochenweise geplant. Wochenenden sind heller dargestellt – eintragen lässt sich dort dasselbe, verlangt wird es nicht.
Beim Anwenden wählst du, ob nur ergänzt oder der Plan dem Template angeglichen wird – letzteres ändert auch Tage, die schon geplant sind.
